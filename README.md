# 駅間ルートナビ

東京近郊のJR・地下鉄・都営地下鉄・主要私鉄を対象にした駅間ルート検索です。駅名のほか住所を入力すると、国土地理院の住所検索サービスと OpenStreetMap を利用して対応する最寄り駅を検索します。

住所入力時は、出発地・到着地と最寄り駅の直線距離を毎分 80m として換算した徒歩時間の目安を、経路の合計時間に含めます。

## 起動方法

住所検索を利用するには、Node.js 18 以降で次を実行し、`http://localhost:4173` を開きます。

```sh
node server.js
```

## 対応する私鉄

- 小田急小田原線
- 京王線・井の頭線
- 東急東横線・田園都市線・目黒線
- 京急本線
- 西武新宿線

所要時間と乗り換え時間は簡易的な目安です。実際の運行状況・列車種別・時刻表は反映していません。

## 主要な観光地

検索フォームの「主要な観光地から到着駅を選ぶ」から、東京メトロ・都営地下鉄路線図に掲載されている主な観光地を選ぶと、最寄り駅を到着駅へ入力できます。
